This folder contains a small redirect to the existing `waaheda_hb` project folder.

Access on GitHub Pages: `https://ugolabbe.github.io/waaheda` -> redirects to `/waaheda_hb/`.

If you prefer a clean path `/waaheda` without redirect, either:
- rename `waaheda_hb` -> `waaheda`, or
- copy the contents of `waaheda_hb` into this folder.
